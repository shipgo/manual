# Monitoreo en Tiempo Real

## Cómo Leer el Mapa

El mapa muestra la **posición en vivo** de cada vehículo activo. Cada ícono representa un chofer y su color refleja el estado del viaje ([ver estados](../introduccion/conceptos-basicos.md)).

- Hacé clic en un ícono para ver el detalle del viaje: paradas completadas, pendientes y tiempo estimado.
- Usá los filtros del panel lateral para mostrar solo flotas en estado Rojo o Amarillo.

## Qué Hacer ante una Incidencia (Vehículo en Rojo)

{% stepper %}
{% step %}
**Identificá el viaje afectado** en el mapa o en la lista de alertas del [Centro de Acción](centro-de-accion.md).
{% endstep %}

{% step %}
**Abrí el detalle del viaje** y revisá la incidencia reportada por el chofer.
{% endstep %}

{% step %}
**Tomá acción:** contactá al chofer por el canal interno, reasigná paradas a otro vehículo, o escalá al administrador si es necesario.
{% endstep %}

{% step %}
**Actualizá el estado** del viaje una vez resuelta la situación.
{% endstep %}
{% endstepper %}
