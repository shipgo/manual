**Quién puede usarla:** Superusuarios y Administradores al crear el envío; el chofer la pide al entregar.

La **palabra de entrega** es una clave de dos palabras (por ejemplo, `LUNA-PERRO`) que el destinatario recibe por email junto con el código de seguimiento. Cuando le entregan el paquete, el destinatario se la dicta a quien entrega. Así se confirma que el envío llegó a la persona correcta.

## Al crear el envío

En el formulario de [Crear envío](/manual/panel-web/gestion-envios-viajes/), al final, hay una tarjeta **Palabra de entrega** con el interruptor **Generar palabra de entrega**. Viene **activado**.

- **Activado:** ShipGo! genera la palabra al registrar el envío y se la manda por email al destinatario.
- **Desactivado:** el envío se entrega sin palabra. Los avisos por email no la mencionan y la entrega no la exige.

:::caution
La decisión se toma **solo al crear** el envío. Después no se puede generar, cambiar ni quitar la palabra.
:::

:::note
Por seguridad, el panel **no muestra** la palabra de ningún envío. Solo la conoce el destinatario.
:::

## Al entregar

- **Chofer en la app:** si el envío tiene palabra, el chofer la pide al destinatario antes de confirmar la entrega. Ver [Entregas](/manual/app-mobile/ejecucion-entregas/).
- **Entrega desde el panel:** si registrás una entrega o un retiro desde el [detalle del envío](/manual/panel-web/gestion-envios-viajes/), el campo **Palabra de entrega** aparece solo si el envío tiene palabra.

<Steps>

1. Pedile la palabra al destinatario.
2. Escribila en el campo **Palabra de entrega**. No importan las mayúsculas, las tildes, los guiones ni los espacios: `luna perro` equivale a `LUNA-PERRO`.
3. Confirmá la entrega.

</Steps>

Si la palabra no coincide, ShipGo! muestra el error **La palabra de entrega ingresada no coincide con la registrada para este envío** y la entrega no se registra hasta que la corrijas.

:::tip
En la pantalla de entrega del panel, el campo **Palabra de entrega** se presenta como opcional. Si el envío tiene palabra, igual conviene completarla: el sistema la valida y rechaza la entrega si falta o es incorrecta.
:::
