# Roles de Usuario

ShipGo! tiene tres roles con responsabilidades distintas:

{% tabs %}
{% tab title="Administrador" %}
Tiene acceso total al sistema. Gestiona usuarios, configura la plataforma y accede a todos los reportes analíticos. Es quien define las reglas del negocio.
{% endtab %}

{% tab title="Operador Logístico" %}
Opera el día a día. Ingresa paquetes al sistema, arma viajes, asigna choferes y monitorea el estado de la flota desde el panel web.
{% endtab %}

{% tab title="Chofer" %}
Usa la app móvil durante su jornada. Ve su ruta asignada, marca entregas como exitosas o fallidas y reporta incidencias desde el campo.
{% endtab %}
{% endtabs %}
