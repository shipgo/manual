# Inicio de Jornada

{% hint style="info" %}
Esta sección es para choferes. Los pasos son cortos y directos.
{% endhint %}

{% stepper %}
{% step %}
**Abrí la app ShipGo!** e ingresá con tu usuario y contraseña.
{% endstep %}

{% step %}
**Tocá "Ver mi ruta de hoy"** en la pantalla principal. Vas a ver la lista de paradas del día en orden.
{% endstep %}

{% step %}
**Revisá las paradas** antes de salir: dirección, nombre del destinatario y observaciones especiales.
{% endstep %}

{% step %}
**Tocá "Iniciar jornada"** cuando estés listo para salir. Esto activa el tracking en tiempo real.
{% endstep %}
{% endstepper %}
