# Ejecución de Entregas

Al llegar a cada parada, registrá el resultado desde la app.

## Entrega Exitosa

{% stepper %}
{% step %}
Tocá la parada activa en tu lista de ruta.
{% endstep %}

{% step %}
Seleccioná **"Entregado"**.
{% endstep %}

{% step %}
Tomá una foto del paquete en la puerta o pedí la firma del destinatario.
{% endstep %}

{% step %}
Confirmá. La parada queda en verde y pasás a la siguiente automáticamente.
{% endstep %}
{% endstepper %}

## Entrega Fallida

{% stepper %}
{% step %}
Tocá la parada y seleccioná **"No entregado"**.
{% endstep %}

{% step %}
Elegí el motivo: cliente ausente, dirección incorrecta, paquete rechazado, etc.
{% endstep %}

{% step %}
Confirmá. El operador recibirá una alerta automática.
{% endstep %}
{% endstepper %}
