# Reporte de Incidencias

Si algo impide que sigas con la ruta normal, reportalo desde la app. El operador lo verá de inmediato.

## Cómo Reportar

{% stepper %}
{% step %}
Tocá el botón **"Reportar Incidencia"** (ícono de alerta en la barra superior).
{% endstep %}

{% step %}
Seleccioná el tipo de incidencia.
{% endstep %}

{% step %}
Agregá una nota si es necesario y confirmá.
{% endstep %}
{% endstepper %}

## Tipos de Incidencia

| Situación | Qué seleccionar |
|-----------|-----------------|
| Hay mucho tráfico | Demora por tráfico |
| El vehículo se rompió | Falla mecánica |
| El cliente no está en la dirección | Ausencia del destinatario *(esto también se reporta desde la parada)* |
| Otro problema | Otro — y describilo en la nota |

{% hint style="warning" %}
No abandones la ruta sin reportar la incidencia. El operador necesita saberlo para reasignar paradas.
{% endhint %}
